## Desglose por Dispositivo

### 1. Asistente de Voz: Amazon Echo Pop — 30€

El Echo Pop es el punto de entrada más barato al ecosistema Alexa. Con él puedes:
- Controlar por voz todas las luces y enchufes
- Poner música, podcasts, audiolibros
- Consultar el tiempo, noticias, tráfico
- Crear rutinas (automatizaciones por voz)
- Hacer compras por voz
- Llamar a otros dispositivos Echo

### 2. Luces Inteligentes: 3x TP-Link Tapo L530E — 30€

Tres focos inteligentes para las habitaciones principales:
- **Salón:** Control por voz y móvil, colores para ambiente
- **Dormitorio:** Modo luz cálida para dormir, temporizador de apagado
- **Cocina/Pasillo:** Automatización con sensor de movimiento

Cada foco cuesta 8.99€, se conecta directamente a WiFi y funciona con Alexa y Google Home.

### 3. Enchufes Inteligentes: 2x TP-Link Tapo P110 — 26€

Dos enchufes para automatizar electrodomésticos:
- **Enchufe 1:** Lámpara de mesa → encender por voz
- **Enchufe 2:** Cargador de móvil → temporizador nocturno
- **Bonus:** Miden consumo eléctrico en tiempo real

### 4. Sensores de Movimiento: 3x SONOFF SNZB-06P — 40€

Tres sensores para automatizaciones y seguridad:
- **Salón:** Encender luces al detectar movimiento
- **Pasillo:** Iluminación nocturna automática
- **Entrada:** Alerta de seguridad cuando no hay nadie

**Nota:** Necesitas un hub Zigbee. El **Sonoff Zigbee 3.0 Dongle Plus** (20€) conectado a un Raspberry Pi o una PC antigua sirve como hub.

### 5. Cámara Interior: TP-Link Tapo C210 — 30€

Cámara 2K con rotación 360°, visión nocturna y alertas de movimiento. Sin suscripción obligatoria.

### 6. Sensores de Puerta: 2x SONOFF SNZB-04 — 22€

Dos sensores de contacto para:
- **Puerta principal:** Alerta cuando se abre
- **Ventana salón:** Alerta de seguridad

## Cómo Funciona Todo Junto

### Mañana (7:00)

```
"Alexa, buenos días"
    → Encender luz cocina
    → Decir el tiempo
    → Apagar sensores de noche
```

### Al salir de casa

```
Rutina automática (geofencing o voz):
    → "Alexa, me voy"
    → Apagar todas las luces
    → Activar sensores de seguridad
    → Activar cámara de seguridad
```

### Al llegar a casa

```
Sensor de movimiento en pasillo detecta:
    → Encender luz pasillo
    → Notificar en móvil "Has llegado a casa"
```

### Por la noche

```
"Alexa, buenas noches"
    → Apagar todas las luces
    → Encender luz dormitorio al 10%
    → Activar alarma
    → Activar cámaras
```

## Errores al Comprar Barato

1. **No comprar el hub:** Los sensores Zigbee necesitan un coordinador
2. **Comprar solo WiFi:** Los dispositivos WiFi baratos saturan el router
3. **Olvidar el cableado:** Los interruptores inteligentes necesitan cableado eléctrico
4. **No verificar compatibilidad:** Algunos dispositivos solo funcionan con su propia app
